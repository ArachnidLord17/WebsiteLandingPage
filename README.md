## Selected work

### [Salus](https://github.com/SanjithTammana/redcrosssalus)

Team project for the 2024 American Red Cross Hackathon. Salus is a React and Next.js first-aid practice platform with local quiz, flashcard, and matching-game data, a resource page, and separate practice and emergency chat modes. The client sends chat history and a mode-specific prompt to a Next.js API route, which calls Groq.

**Technologies:** React, Next.js, Material UI, Groq API, JavaScript

### [DebateBot](https://github.com/SanjithTammana/DebateBot)

Personal Streamlit experiment for asking debate questions against a local knowledge base. It extracts TF-IDF keywords from a question, finds matching lines in the source file, and passes the resulting context to Groq.

**Technologies:** Python, Streamlit, scikit-learn, Groq API
